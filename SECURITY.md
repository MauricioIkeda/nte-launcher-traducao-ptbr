# Política de segurança

## Versões com suporte

Somente a versão mais recente publicada do launcher recebe correções de
segurança.

## Relatar uma vulnerabilidade

Use a opção privada **Report a vulnerability** na aba
[Security](https://github.com/MauricioIkeda/nte-launcher-traducao-ptbr/security/advisories/new).
Não abra uma issue pública com detalhes que permitam explorar a vulnerabilidade.

Inclua a versão afetada, o impacto observado, passos mínimos para reproduzir e,
quando possível, uma sugestão de correção. Não inclua credenciais ou dados de
terceiros.
